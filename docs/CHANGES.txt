--------------------------------------------------------------------------------
LƯU Ý KHI CHẠY
--------------------------------------------------------------------------------

- Nếu đã có DB cũ: chạy migration mới để tạo bảng QrVisits:
    dotnet ef database update --project Zoo.DAL --startup-project Zoo.Api

- Nếu đã có tài khoản admin từ DbSeeder cũ (hash SHA256):
  Cần xóa row trong bảng AdminUsers rồi khởi động lại backend để seed lại
  với hash đúng (PBKDF2), HOẶC chạy:
    dotnet run --project Zoo.Api -- --seed-admin

- QR phải dùng URL có tham số ?source=qr để ghi nhận lượt.
  Ví dụ: https://your-domain.com/?source=qr
  Thêm ?demo=true để đánh dấu lượt demo (loại khỏi báo cáo vận hành).
